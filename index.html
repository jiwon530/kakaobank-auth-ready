연동 사전점검

API 테스트 이후, 인증 실패 응답을 우리 서버가
올바르게 처리하는지 운영 전에 점검합니다.

✓

본인확인 흐름 사전점검

카카오뱅크 인증서 본인확인 API를 연동한 제휴사 테스트 서버 점검

  • 별도 로그인 없이, 계약된 제휴사에 발급되는 사전점검 전용 토큰으로 이용합니다. 운영 credential은 사용하지 않습니다.
  • 샌드박스가 정상 · 실패 상황을 재현하고, 제휴사 테스트 서버의 점검 결과 조회 API로 최종 처리 결과를 받아 판정합니다.
  • 점검 결과 조회 API는 이번 제안에서 새로 정의하는 연동 규격입니다.
  • 점검 결과서는 연동 확인 자료이며, 보안 인증이나 보증이 아닙니다.

① 테스트 환경 연결 및 검증 설정

계약된 제휴사의 점검 권한을 확인한 뒤, 제휴사 테스트 서버를 연결해 인증 결과 처리를 검증합니다.

본인확인 API

카카오뱅크 인증서를 통한 본인확인 요청

  • 본인확인 API는 먼저 접근토큰 요청 API를 수행후 발급된 접근토큰(access_token)을 사용하여야 이용할 수 있습니다.
  • 본인확인결과요청 API는 본인확인요청 API 응답의 composite_key가 필요합니다.
